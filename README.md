# 极域电子教室 UDP 重放攻击脚本

## 原理

极域电子教室（极酷）采用 **UDP 私有协议**通信：

- **教师端**：按私有二进制协议封装指令，向学生端端口发送 UDP 包。
- **学生端**：监听 `UDP 4705`，收到包后**无认证、无校验**直接执行。

这意味着：只要构造出符合协议格式的指令包，向任意学生端 IP 的 4705 端口发送，即可被当作"教师端指令"执行——**无需任何身份认证**。

## 攻击方式

> 伪造教师端 → 发送符合协议的 UDP 指令包 → 学生端误认为是教师端在发命令 → 执行指令

本质是一个**UDP 重放/伪造**攻击：学生端无法区分"真教师端"和"伪教师端"。

## 使用方法

```bash
# 单台学生机
192.168.1.100

# IP 范围（批量）
192.168.1.1-192.168.1.5

# 子网全段（/24 广播）
192.168.1.0/24
